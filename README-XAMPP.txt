RHYTHM SPACE - WEBSITE XAMPP

1. Extract folder 'rhythm-space-website' ke C:\xampp\htdocs\
2. Buka XAMPP Control Panel.
3. Start Apache.
4. Buka browser:
   http://localhost/rhythm-space-website/
